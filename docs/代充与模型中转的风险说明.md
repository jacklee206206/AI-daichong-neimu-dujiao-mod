# 订阅代充与模型 API 中转的风险说明

整理日期：2026-10-06。

我在搭建前比较过两种业务，当时更愿意从具体的订阅交付入手。下面把当时的业务取舍与公开法规能够支持的结论分开。实际风险需要结合采购来源、经营主体、网络方式、资金路径和数据处理判断，不能仅按“代充”或“中转站”的名字定性。

## 先分清两种 API

**商品采购 API**接收商品与规格、扣采购余额并返回卡密；**模型 API 中转**接收用户输入，向模型发起推理请求，再返回生成内容。前者能减少自行经手持续对话的环节，仍然可能涉及订单、账号信息和跨境数据。

## 代充的资金风险看交易实质

真实订阅交付与用点卡、代付、储值掩护货币兑换，交易实质不同；但商品真实交付、使用聚合支付或能开发票，都不能单独证明采购和资金结算合法。

2019 年两高司法解释的前提，是行为已经属于非法支付结算或非法买卖外汇。通常非法经营额 **500 万元以上**或违法所得 **10 万元以上**，达到“情节严重”的数额标准；**250 万元以上**或违法所得 **5 万元以上**，还须伴随曾因同类犯罪受过刑事追究、二年内同类行政处罚、拒不配合致赃款无法追缴或其他严重后果之一。多次未经处理的同类行为金额还可能累计。[司法解释第二、三、六条](https://www.court.gov.cn/zixun/xiangqing/141542.html)

因此，商城销售流水与涉案非法经营额需要区别，250 万元也不是经营安全线。未达到刑事追责标准的非法买卖外汇，仍可能承担行政责任。[最高检与外汇局 2025 年说明](https://www.safe.gov.cn/zhejiang/2025/0513/2184.html)

已有可比的汇兑处罚案件。例如官方公布的“郭某钊等人非法经营帮助信息网络犯罪活动案”，网站以储值、代付等形式，经 USDT 完成外币与人民币兑换，再向指定账户付款，相关人员已被判刑。这是汇兑案件，不能写成 ChatGPT 订阅代充案件；同样，也不能把没有找到完全同类公开案件解释为没有风险。[最高检与外汇局典型案例](https://www.safe.gov.cn/safe/2023/1227/23710.html)

USDT 也要单独核查。2026 年现行通知明确泰达币等不具有法偿性，不应且不能作为货币在市场流通使用，并严格禁止境内法币与虚拟币兑换等相关业务。该通知已废止 2021 年旧通知。自动识别链上付款说明技术功能成立，不构成收款、兑换或跨境结算合规的证明。[银发〔2026〕42 号](https://www.csrc.gov.cn/csrc/c100028/c7614318/content.shtml)

## 模型中转承担的服务与数据责任

**网络方式。** 境外接口调用需要核查实际联网方式。禁止未经允许自行建立或使用其他国际联网信道，不等于任何一个境外 HTTP 请求都自动构成犯罪。还需区别模型请求转发与向他人提供联网通道。[国际联网暂行规定第六、十四条，2024 修订全文](https://xzfg.moj.gov.cn/law/download?LawID=1713&type=pdf)

**对外服务。** 面向境内公众提供生成式 AI 服务时，使用 API 的形式也可能属于服务提供者。是否需要安全评估、备案或电信许可，要按具体服务与适用条件判断；收费本身不足以直接推出非法经营罪。[生成式 AI 暂行办法第二、十七、二十二条](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[电信条例第七条](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_02c93c77cf684842bd36ae66cf8e412a.html)

**数据出境。** 提问可能含个人信息、商业秘密或重要数据。个人信息出境涉及依法告知、单独同意、影响评估与必要保护措施；应按实际数据类别、数量和适用条件选择安全评估、标准合同、认证等路径或判断是否符合豁免。代充涉及的账号、Session、订单资料，同样不能忽略。[个人信息保护法第三十八、三十九、五十五条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

2024 年数据跨境规定对部分场景免予安全评估、标准合同或认证；2026 年小型个人信息处理者规则又简化了部分措施。这些安排仍须依法履行相应个人信息保护义务，不能理解为规模小就无需处理数据风险。[2024 规定第五、十条](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)、[2026 小型处理者规定第十、十四条](https://www.cac.gov.cn/2026-07/24/c_1786638889704872.htm)

**经营记录。** 网络日志、调用记录、订单与资金记录可能用来查明业务实质。记录可以成为证据，是否违法仍须看所证明的具体行为；不能据此断言所有调用内容都会保存，或保存日志本身就是犯罪。现行网络安全法规定相应的网络日志留存义务，也不能用该义务解释为无限保存用户提问。[2025 修正、2026 生效的网络安全法第二十三条](https://shca.miit.gov.cn/zwgk/zcwj/flfg/art/2025/art_c502acb4374848e0a7752925c72fe775.html)

## 已确认的中转处罚与不能混用的传闻

国家网信办 2026 年 9 月 15 日通报：江苏一家公司的两个网站以 API 中转形式调用多个大模型，提供对话、问答服务，因未按规定开展安全评估，被责令改正并警告。通报没有说明模型来自境外，也没有刑事入狱信息。[官方通报第 10 起](https://www.cac.gov.cn/2026-09/15/c_1790876152357946.htm)

国家安全部此前也提示部分中转站的资质、隐私、接口来源和境外数据传输风险。[国家安全部风险提示，新华网转载](https://www1.xinhuanet.com/politics/20260608/12e9c6edd8be40549249860b574aa9ea/c.html)

匿名站长自述刑拘或取保候审，不能直接当成已生效判决；出售翻墙工具、盗取密钥、非法获取数据等案件，也不能概括成普通 API 转发必然被判刑。文章采用已确认的行政处罚来说明监管责任，没有把这类传闻写成定论。

## 我当时的选择与需要继续做的事

我当时认为具体商品交付的范围更集中，决定从这里开始。持续经营时，还需要核实上游采购授权、支付与资金结算、账号凭据处理及客户权益。先比较风险可以帮助选择业务，完整合规结论则需要结合实际合同、资金链和系统交由熟悉这些领域的专业人士判断。
